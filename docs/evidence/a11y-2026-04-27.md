## target-size (WCAG 2.5.5 AAA / 2.2 2.5.8 AA)

`e2e/target-size.spec.ts` で 3 件評価:

| テスト | 検証範囲 | しきい値 | 結果 |
|---|---|---|---|
| login画面 | 全visible button | WCAG AA (24×24 px) | **通過** |
| メイン画面 (login + 同意済) | 全visible button | WCAG AA (24×24 px) | **通過** |
| 主要操作button | 「開く」「SOAPを抽出する」「ログアウト」 | WCAG AAA (44×44 px) | **通過** |

`document.querySelectorAll('button')` を取得、`getBoundingClientRect()` で測定、`Math.min(width, height)` がしきい値以上であることをassert。Next.js dev overlayのbutton (`nextjs-portal` / `[data-nextjs-toast]`) は本番buildに出ない要素のため計測対象から除外している。
